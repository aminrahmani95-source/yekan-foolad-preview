این مخزن فقط **خروجی ساخته‌شده** سایت است و به‌صورت خودکار از مخزن
خصوصی سورس به‌روز می‌شود. دستی ویرایشش نکنید — هر تغییری با دیپلوی
بعدی پاک می‌شود.

🔗 https://aminrahmani95-source.github.io/yekan-foolad-preview/

لینک ایمیل مستقیم نشان می‌دهد. این نسخه `noindex` است و در نتایج
جستجو ظاهر نمی‌شود.
